## 💡 The Problem & The Vision

Most technical interview prep platforms only test LeetCode-style algorithm puzzles. However, engineering interviews at top tech companies (Meta, Google, Apple, Airbnb, Stripe) heavily evaluate **Frontend & UI System Design** — asking candidates how to architect complex modal flows, manage draft vs global state, virtualize 5,000-item lists, and design resilient error boundaries.

**Stackwa** bridges this gap by unifying:
1. **Algorithmic Problem Solving** powered by **Interview Cake's** progressive 3-tier hint pedagogy and **Scrimba's** interactive codecast explainer embeds.
2. **Frontend UI System Design Studio** inspired by **Mobbin's** production UI flows (Linear, Airbnb, Spotify) with interactive component hierarchy trees and state architecture blueprints.
3. **AI Socratic Mock Interviewer** that evaluates candidate code, checks Big-O time and space complexity, and generates an **Interview Readiness Scorecard**.
4. **Cloud Infrastructure** deployed with zero downtime on **DeployXA** and backed by **Cloud Firestore** for cross-device progress sync.

### 1. 🍰 Interview Cake Pedagogy (DSA Arena)
* Solves coding challenges using Interview Cake's famous **Progressive Hint Engine**:
  * **Tier 1:** Clarifying Questions & Constraints.
  * **Tier 2:** Data Structure & Greedy Traversal Clues.
  * **Tier 3:** Subsumed Ranges, Negative Edge Cases & Space Targets.
* Prevents students from giving up or spoiling answers prematurely.

### 2. 📱 Mobbin Design System Studio
* Evaluates candidates on real-world production UI patterns curated from **Mobbin**:
  * **Linear:** Command Palette (`Cmd + K`), keyboard focus trapping, and fuzzy search virtualization.
  * **Airbnb:** Filter drawer, price distribution histogram, and draft vs global state isolation.
  * **Spotify:** Persistent mini-player audio context, drag-and-drop queue, and optimistic updates.
* Includes interactive component trees, state blueprints (Local vs Global vs Server Cache), and system design quizzes.

### 3. 🎥 Scrimba Interactive Codecast Embeds
* Seamlessly switches from the code editor to a **Scrimba interactive codecast**.
* Candidates can pause, scrub, and directly edit the code mid-video without switching contexts.

### 4. ☁️ DeployXA Cloud Deployment
* Automated container builds and continuous zero-downtime deployment.
* Delivers blazing-fast response times and SSL-secured URLs for the hackathon judges.

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/glixzytechmain-create/stackwa.git
   cd stackwa
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser!

4. **Build for production:**
   ```bash
   npm run build
   ```
